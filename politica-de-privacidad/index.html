Política de Privacidad

Última actualización: 29 de septiembre de 2026

Esta Política de Privacidad describe cómo la aplicación interna FIN - Interlan, operada por INTERLAN PERU, utiliza la información autorizada mediante servicios de Google para automatizar procesos administrativos y financieros internos.

1. Finalidad de la aplicación

FIN - Interlan se utiliza para identificar y procesar notificaciones de operaciones financieras recibidas por correo electrónico, registrar movimientos internos y facilitar su revisión y clasificación administrativa.

2. Datos a los que puede acceder la aplicación

Cuando un usuario autoriza el acceso a Gmail, la aplicación puede leer mensajes necesarios para su funcionamiento, incluyendo contenido del correo, asunto, remitente, destinatario, fecha, identificadores del mensaje y otros metadatos asociados.

3. Uso de la información

La información obtenida se utiliza únicamente para fines internos relacionados con la identificación, validación, registro y conciliación de movimientos financieros y administrativos de INTERLAN PERU.

4. Limitación del acceso

El acceso está restringido a cuentas autorizadas por INTERLAN PERU. La aplicación no está diseñada para uso público masivo ni para ofrecer acceso a terceros ajenos a la organización.

5. Compartición de datos

INTERLAN PERU no vende la información obtenida mediante las APIs de Google. Los datos pueden ser procesados por la infraestructura técnica necesaria para operar la aplicación, como servidores y servicios de automatización administrados por INTERLAN PERU.

6. Conservación y seguridad

Los datos se conservan únicamente durante el tiempo necesario para cumplir los fines administrativos y operativos descritos. Se aplican medidas razonables de control de acceso, autenticación y protección de la infraestructura.

7. Uso de APIs de Google

El uso y transferencia de información recibida desde las APIs de Google se realiza de acuerdo con las políticas aplicables de Google, incluyendo los requisitos de uso limitado de datos cuando correspondan.

8. Revocación del acceso

El usuario puede revocar el acceso concedido a la aplicación desde la configuración de seguridad de su Cuenta de Google. Al revocar el acceso, la aplicación dejará de poder consultar los datos protegidos por dicha autorización.

9. Contacto

Para consultas relacionadas con privacidad o tratamiento de datos, contáctanos mediante el canal oficial de INTERLAN PERU.
